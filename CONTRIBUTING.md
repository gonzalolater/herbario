# Guía de Contribución a Herbario Químico Artesanal 🌿

¡Gracias por interesarte en contribuir al proyecto de **Herbario Químico Artesanal**! Valoramos las sugerencias, reportes de errores y mejoras en el código o en el diseño.

Para mantener una colaboración ordenada y fluida, te pedimos que sigas las siguientes pautas.

---

## 🚀 ¿Cómo puedo contribuir?

### 1. Reportar un problema (Issue)
Si encontraste algún error visual, falla en el envío del formulario o propuesta de mejora:
- Revisa primero en la pestaña de **Issues** si el problema ya fue reportado.
- Si no está reportado, crea un nuevo *Issue* describiendo:
  - El comportamiento esperado frente al comportamiento real.
  - Pasos claros para reproducir el error.
  - Capturas de pantalla si aplica (por ejemplo, errores de diseño en dispositivos móviles).

### 2. Proponer cambios en el código (Pull Request)
Si querés colaborar directamente con código o mejoras en los estilos:
1. **Haz un Fork** del repositorio a tu propia cuenta de GitHub.
